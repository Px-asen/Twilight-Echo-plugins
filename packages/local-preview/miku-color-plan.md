# Miku 配色实施计划

状态：待实施。0.4.1 只降低背景蒙版，以下颜色尚未应用。

## 方向

青绿为主色，浅色以奶白和淡青承接首页插画，深色以墨青承接蓝天背景。
不增加舞台霓虹、发光描边或新的布局。保留插画本身颜色，不给整张图片套主色色相。

## 实施顺序

1. 通过插件 structured.variants.pureWhite/dark.tokens 声明宿主登记的主题令牌。
   先核对 theme-contract.json，建立主色阶、灰阶、表面和文字映射，不复制宿主业务实现。
2. 统一导航选中、按钮、开关、滑块、进度条、输入焦点和歌曲选中行。悬停使用轻微
   青绿底色变化，按下略加深；键盘焦点用清晰描边，不用持续光晕。
3. 统一首页卡片、设置卡片、下拉菜单、弹窗与底部播放器。正文及悬浮菜单使用足够实的
   底色，保留背景在空白处可见；不要全局降低所有卡片透明度。
4. 粉色仅用于收藏与少量装饰。错误保持红色、警告保持琥珀色；音源品牌标识、专辑
   封面和原始图标不强制改色。
5. 检查真实组件在深浅色、背景高低亮度区域和宽窄窗口中的显示。普通文字目标
   对比度至少 4.5:1，大文字及必要的控件边界至少 3:1；在实际混合背景上检查。
6. 运行主题与插件门禁，记录已有失败和新增问题；打包下一版并提供深浅色对照。

## 交付边界

本计划不新增宿主设置面板、不改页面布局、不增加运行时脚本。
配色统一后再评估是否需要开放用户可调颜色参数。
