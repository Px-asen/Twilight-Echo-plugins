# Miku 导航 0.7.1 验证

## 改动

- 全局蒙版各档降低 5 个百分点。
- 本地首页与流媒体每日推荐主卡片共用插画、渐变蒙版、定位及深浅色/窄屏参数，专辑封面与按钮保持原布局。
- 流媒体详情列表（stage-rows）与搜索表格（track-table-wrapper）在 streaming-content 容器绘制与本地相同的向日葵背景和四边渐隐，内部滚动不移动背景。
- 插件保持仅 CSS 和结构化变量；未修改宿主源码。

## 验证结果

- 本地真实首页模板：12 组深浅色、窗口宽度与玻璃开关组合通过，几何位置、图片加载、封面可见和按钮检查通过。
- 流媒体卡片模拟：8 组深浅色、宽度与材质组合通过，图片解码、蒙版、布局不变和点击目标通过。
- 流媒体详情/搜索滚动：24 次原始背景像素比较通过（深浅色 × 两种宽度 × 两种列表 × 3 个滚动距离）。比较时将前景设为 opacity 0，排除表格折叠边框残留。
- 本地列表：18 次固定背景滚动比较通过。
- 全局：16 组场景、宽度和深浅色检查通过。
- 修改的源码经宿主 Prettier 配置格式化，构建和打包通过；38 个包内文件与源文件逐字节一致。
- test:themes：255 通过、1 失败，仍为宿主硬编码颜色基线检查。
- test:plugins：389 通过、1 失败、1 跳过，仍为宿主歌词 IPC 旧源码匹配检查。

图片为组件模拟预览，流媒体封面为占位内容。没有执行完整客户端安装或真实账号、音频播放验证。
