# Miku 导航

Twilight Echo 的初音未来主题，本地预览版 `0.9.4`。

## 0.9.4 滚动性能

将全页面 `body:has(.app-shell)` 子树查询收窄到 `#app` 的直接子节点，移除固定背景附着；歌曲列表表头改用更实的蒙版，取消表头背景模糊，减少滚动重绘。保留插画、配色与独立窗口隔离，不改变宿主液态玻璃设置。

## 0.8.0 设置控件细节

设置的小按钮采用青绿细边、柔和圆角和浅色悬停底；输入框、下拉框、分段按钮、开关和滑块同步主题配色。设置分组及设备/DSP 小面板采用 94% 卡片底色蒙版和轻阴影。保留控件尺寸与开关位置逻辑，提供键盘聚焦描边和禁用状态，危险操作沿用宿主的警示色。未增加人物素材。

## 0.7.0 抱花全局背景

全局背景更换为用户提供的 `101123738_p0.jpg`，采用等比例 cover、中心偏上的取景和横向渐变蒙版。首页与设置加强蒙版，兼容深浅色和窄窗口。原始图片不变，包内使用等比例压缩的 WebP。

歌曲表格保留向日葵初音，使用独立图片变量和不透明底色隔开全局人物，沿用靠右固定及四边渐隐，歌曲滚动不改变人物位置。此版本取代 0.6.0 的全局天空裁切。

使用用户提供的 30 张透明 PNG，覆盖三个菜单：

- 主导航 13 项：首页、所有歌曲、艺术家、专辑、流派、歌单、聚合歌单、文件夹、
  最近播放、流媒体、电台 / 播客、网络源和导入歌曲。
- 设置导航 9 项：常规、播放、DSP、缓存、性能、外观、桌面歌词、快捷键和关于。
- 流媒体导航 8 项：主页、发现歌单、音乐库、音乐云盘、最近播放、Bilibili、
  聚合歌单和本地模式。入口仍按宿主的音源可用性显示。

三组图片的基础视觉尺寸均为 28px，保留原有图标布局占位、菜单文字位置与按钮高度。
设置导航继续使用宿主原有的选中放大和悬停旋转；点击和键盘操作仍由宿主管理。

### 0.5.0 配色说明

`palette.mjs` 声明深浅两套主题令牌，经 `build.mjs` 写入 manifest 的

设置表面、播放器底色、进度轨道和均衡器颜色。未覆盖的语义色及全屏歌词等令牌

保留 0.4.1 的背景蒙版。运行时无脚本，不改布局，不新增设置面板。

### 导入插件

1. 在 Twilight Echo 的「扩展中心」选择「从本地安装包 (.tep)」。
2. 安装 `com.twilightecho.theme.miku-navigation-0.6.2.tep` 并启用插件。
3. 在主题工作室的「插件主题」中选择「Miku 导航」，点击应用。

这是一个独立主题。宿主切换插件主题时会采用默认布局模式；它不会叠加并继承另一个
插件或内置主题的专属布局。此主题自身的 CSS 修改导航图标、本地首页播放卡片与主窗口背景。

### 首页卡片处理

首页「正在收听 / 上次播放」卡片使用用户提供的初音插画，替代原有模糊专辑背景。
文字、按钮、播放进度与右侧真实专辑封面继续由宿主管理，布局不变。没有歌曲时的
空库引导与流媒体首页不受影响。

插画保留原图，通过 CSS 将上半身放在卡片中间偏右，左侧、底部与右边缘使用渐变
蒙版。深色模式自动降低亮度和饱和度；900px 以下沿用宿主的纵向布局，并淡化背景。
液态玻璃模式也保留文字区蒙版。主题不添加动画或运行时脚本。

`artwork/miku-home.jpg` 是完整的 1969×1599 原图；`home.css` 中的
`--miku-hero-size`、`--miku-hero-x`、`--miku-hero-y`、`--miku-hero-opacity` 和
`--miku-hero-mask` 控制宽屏裁切、位置、浓度与左侧蒙版范围。修改后运行
`node build.mjs` 重新构建。这些是源文件参数，当前没有新增宿主设置面板。

## 素材与构建

- 原素材包：用户提供的 `TwilightEcho_Miku_Nav_Icons/transparent_512/`，以及
  `TwilightEcho_Miku_Settings_Streaming_Icons` 内的两组 `transparent_512/`。
- `icons/`：从 512px 原图缩小到 96px 的 RGBA PNG，保留透明通道。
- `icons.json`：30 个菜单与图片的映射，设置和流媒体图片分别放在 `icons/settings/`
  与 `icons/streaming/`。
- `build.mjs`：构建时把 PNG 与首页 JPEG 内嵌到 CSS，插件运行时不执行脚本。
- `theme.css`：宿主实际加载的主题样式。

在本目录运行 `node build.mjs` 可重新生成 `theme.css`。图片已经随源代码保存，构建无需
访问用户的图片目录，也不需要下载素材。CSS 使用 data URI，避免图片相对路径被错误地
解析到 renderer 文档目录；只隐藏已经配置图片的原图标。

设置导航用定位伪元素显示图片，保留原字形的布局尺寸及宿主动画；其他两组在固定
图标占位上绘制并缩放背景图片。主题不插入 DOM，也不执行运行时脚本。

生成安装包时，将 `plugin.json`、`theme.css`、`icons/`、`artwork/`、`README.md`、`LICENSE` 和
`THIRD_PARTY_NOTICES.md` 复制到临时打包目录，再使用宿主的
`packages/create-twilight-plugin/bin/create-twilight-plugin.cjs pack` 命令打包。
本地预览包保存在外部插件仓库的 `packages/local-preview/`，不登记到插件市场索引。

## 兼容说明

当前按 Twilight Echo 1.2.x 的导航结构制作。普通歌单和聚合歌单共用
`navigation.playlists`，聚合歌单通过当前中文标题单独覆盖；网络源则单独隐藏旧图标
字形。设置导航与流媒体导航按各自菜单内的现有图标类匹配，不依赖菜单顺序。
Bilibili 入口匹配当前的 `pi-video` 类；其他音源若也使用这个类，会显示同一张图片。
宿主更改菜单标题、图标类或 DOM 结构后，需要重新检查对应关系。

设置搜索结果、设置内容区和其余第三方插件菜单不在这批素材的替换范围内。
主题还包含本地首页卡片插画，新增青蓝全局背景，不包含舞台装饰或播放器改版。
