# 莱茵 0.2.11：代理模型、资源预处理与遮蔽缓存

## 行为

- 音乐架按模型在渲染画布中的像素跨度切换三档几何：完整 1000、近中距 488、远距 232 个三角形。边界有回差，避免相机缓动时反复切换。抽出、回位副本和 360° 查看器继续使用完整模型，玻璃材质、光带、阴影、动画与相机算法保留。
- 设置 → 画面与声音 → 画质 → 精细设置新增“模型细节”：自动分级 / 完整模型。默认自动，旧画质参数和帧率保留；可随时切回完整模型。
- 壳体按档位压紧为实例批次，封面和逻辑槽位仍使用原编号。拾取使用低面数盖板代理，共享原槽位矩阵；远处画面外的投影物仍保留，避免错误剔除导致阴影消失。矩阵、相机和画质不变时跳过整个分级重排。
- 环境遮蔽缓存法线、深度及模糊结果。相机、投影、几何、实例、可见性、分辨率或采样参数变化立即刷新。光照颜色、主题和光带仍逐帧绘制；缓存不冻结整幅画面。上下文恢复后重新生成缓存，AO 关闭或低分辨率时保留景深原有回退路径。

## Cook 资源

`npm run cook:render` 从原始建模说明及 GLB 生成两档代理；检查原 GLB SHA-256，避免建模说明与模型不一致。三张内置封面预生成 256 / 1024 最大边的无损 WebP，保持长宽比与透明通道。资源摘要保存在 `public/cooked/manifest.json`；构建前自动更新，生成结果纳入源码，开发时可直接使用。

原模型和原图不改写。运行时缩略图直接读取 256 档，选中、回位副本与查看器按需使用 1024 档；排队中的缩略图可提升为选中图，丢失预处理图时回退原图。外部和个人封面继续使用原有并发、像素和上传预算，不修改音乐文件。WebP 减少传输和源图解码负担，解码后的 GPU 纹理仍为原来的 RGBA 画布；本版没有宣称 KTX2/BCn 显存压缩。为保留回退路径，包内仍包含原图，不能把下载量下降当作安装包同幅缩小。

三张原图合计 7,735,632 字节；六张预处理图合计 2,793,194 字节。代理 GLB 为 54,240 字节。原近看模型 78,948 字节保持不变。

## 验证

Windows Edge / ANGLE D3D11，1440×900，1000 张合成专辑、3 种封面，默认画质。对照旧版 0.2.10，在同一静止场景中：

| 指标 | 0.2.10 | 0.2.11 |
| --- | ---: | ---: |
| 单帧三角形提交量，含后处理 | 1,229,689 | 301,627 |
| 晨雾绘制调用 | 26 | 15 |
| 月影绘制调用 | 27 | 16 |
| 总览壳体三角形 | 611,000（完整池） | 143,288（6 个中距、605 个远距） |

静止场景的缓存帧与同状态强制刷新阴影/AO，RGBA 最大差为 0/255。49 个屏幕拾取采样全部保持原槽位身份；611 个压紧矩阵均能对应原矩阵，数量完整。放大/切回完整档、总览、详情完整模型、快速导航及真实列切换均已检查；运动中缓存持续失效，没有沿用静止深度。

中距代理与完整模型在同状态下平均通道差约 0.103/255，约 0.322% 通道差超过 8/255，边缘最大局部差为 115/255；代理会改变局部几何，不能称为逐像素无损。已人工查看晨雾/月影画布。

GPU 计时受温度和系统负载影响，重复样本有波动；以上提交量下降不等于整机 GPU 占用按同一比例下降。静止时可复用遮蔽；保留的波动、导航和相机动画仍需要实时更新。

`npm test` 覆盖 19 项，包括 Cook 摘要及源码清单一致性、模型外形边界、纹理尺寸/长宽比、LOD 回差、相机/实例/顶点/成员变化失效和既有限帧回归。`npm run check:render-tiers` 在浏览器检查实际分级、像素、拾取、矩阵、详情和导航。原有模型、封面、真实列和呈现检查通过；真实列检查的依赖替身补入了 0.2.10 已引入的矩阵写入函数。

浏览器对照与截图保存在 `.cache/render-tiers/`；原生宿主验证使用独立配置和合成曲库，测试数据不写入日常配置。

原生开发宿主实际安装并启用 0.2.11 包，读取完整 1000 张合成专辑，验证完整模型 → 自动分级即时切换、晨雾/月影与连续行导航，界面内计数约 59–60 FPS、无页面异常。记录中的外层 RAF 采样约 128–130 Hz 是显示器回调频率，不是插件实际提交帧率，也没有用它宣称帧率提升。此次为本机现有 Electron 构建的原生窗口验证，没有重新发布宿主安装包；音频使用静音夹具，未做音质试听。

原生窗口截图与报告另存于本插件 `.cache/render-tiers/native-*`，便于与浏览器对照一起查看。

预处理清单同时生成于 `src/cooked-render-assets.json` 供标准源码导入，避免开发服务器直接导入 public 文件的警告。最终重建后的音乐主程序 SHA-256 与原生验收版本完全一致：`2391a351463f2c842a0074bfe7a426315eabc034d8fac88fbb449601d3d9a3cc`。
