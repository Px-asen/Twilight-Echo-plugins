# 莱茵生命 · 0.2.4 导航性能

继续优化连续切换专辑，沿用 0.2.3 的画质与动画设置。安装新版 `.tep` 即可，已有兼容预览宿主无需重新下载。

## 本轮改动

- 回位副本的壳体材质、shader 回调、1024² 封面画布和纹理复用。只回收已完成回位或已被重新选中的副本，正在运动的副本数量、轨迹和时长保留。闲置池最多 8 个，不随专辑数量增长；代价是保留少量封面与材质内存。
- 复用每帧 612 个槽位坐标及真实列的中心坐标临时对象，减少连续对象分配。
- 相邻卡片直接共用半行坡度采样；跨行循环断点、跨列和远距离切换时重新计算，帧间不保留旧波形。
- 普通坐标范围内直接跳过重定位周期计算，远距离坐标仍沿用原来的重定位规则。
- 封面复用检查请求版本和曲库代次，避免晚到的异步图片覆盖新专辑；替换时清除透明区域，退出时释放闲置资源。

曾测量通用波形缓存方案，实际宿主 CPU 耗时出现回退，最终交付改为直接共享相邻采样，没有采用该方案。

## 场景更新与资源分配

Edge、RTX 5070 Laptop、1366×768 窗口、devicePixelRatio 1.5，内部渲染 2049×1152；1000 个专辑、12 个流派、3 种合成封面。每版模拟 900 帧，频繁换专辑、换列、进入退出总览与详情。下表仅测 `scene.update(..., false)`，不包含 GPU 绘制，也不是实际帧率；不同运行的绝对值会波动。

| 阵列 / 主题 | 更新均值（0.2.3 → 0.2.4） | P95 |
|---|---:|---:|
| 填充 / 晨雾 | 1.751 → 1.430 ms | 3.0 → 2.4 ms |
| 填充 / 月影 | 1.977 → 1.277 ms | 3.4 → 2.2 ms |
| 真实列 / 晨雾 | 0.764 → 0.614 ms | 1.2 → 1.1 ms |
| 真实列 / 月影 | 0.659 → 0.564 ms | 1.2 → 0.9 ms |

每组 66 次有效切换：新建壳体材质组和独立封面纹理从 66 组降至 15 组，结束时活动副本为 0、闲置池为 8。612 个槽位坐标保持对象身份。68 行、9 列的坡度采样从 1224 次最多降到 630 次；加上各槽位中心高度，槽位波形求值从 1836 次最多降到 1242 次，约减少 32%。

## 实际打包宿主

同一预览 EXE、默认图形后端、RTX 5070 Laptop、1920×1080 窗口、devicePixelRatio 1.5。隔离配置中实际索引 1000 张合成专辑、12 个流派，复用 3 种测试封面；每种操作约 6.5 秒，两版均开启 CPU profiler。不是 1000 张独立大图的测试。数值是本次对照样本，受系统负载、温度、导航阶段和采样影响。

| 主题 | 操作 | FPS（0.2.3 → 0.2.4） | P95 帧间隔 | P99 帧间隔 |
|---|---|---:|---:|---:|
| 晨雾 | 120ms 连按 / 反向 | 84.2 → 93.5 | 27.8 → 33.3 ms | 38.9 → 44.3 ms |
| 晨雾 | 横向换列 | 80.1 → 85.8 | 38.9 → 33.4 ms | 55.6 → 61.2 ms |
| 晨雾 | 总览导航 | 99.5 → 105.0 | 16.7 → 16.6 ms | 55.6 → 61.1 ms |
| 晨雾 | 详情导航 | 118.0 → 124.8 | 11.2 → 11.2 ms | 22.3 → 16.8 ms |
| 月影 | 120ms 连按 / 反向 | 83.5 → 95.8 | 33.4 → 38.8 ms | 44.5 → 44.4 ms |
| 月影 | 横向换列 | 56.0 → 67.8 | 55.6 → 50.0 ms | 77.7 → 61.2 ms |
| 月影 | 总览导航 | 76.0 → 110.8 | 16.7 → 16.6 ms | 55.8 → 55.4 ms |
| 月影 | 详情导航 | 117.7 → 124.5 | 11.2 → 11.2 ms | 22.5 → 22.2 ms |

平均帧率在这组对照中提高，但快速连按的 P95 仍有回退，部分 P99 也没有改善，不能称为彻底解决长帧。更早的采样出现明显波动及窗口遮挡后的 1 FPS 降频，因此未用其宣称提升；原始有效复测保存在 native-before.json 和 native-after.json。两版使用相同的禁后台降频测试开关，日常插件没有增加这些开关。

## 画质与回归范围

- 所有采样的实例矩阵、选中专辑、相机和活动副本变换与优化前严格一致，绘制调用和三角形数量一致。
- 日夜主题、填充及真实列，共 16 组 GPU 像素对照。最大平均通道差 0.0354/255，最多 0.000933% 像素有通道差超过 8。部分截图逐像素相同；另一些截图有微小渲染排序差异，并非宣称全部逐像素相同。
- 分辨率、阴影、AO、景深、玻璃折射、封面尺寸及各向异性参数一致。主参考运动算法、相机、光照和开场源文件没有改动。此前移除的开场底部提示和按钮仍保持移除。
- 真实画布检查覆盖透明封面替换、旧异步回调、退休副本、曲库刷新、画质切换和释放。交互、光照、入场、真实列矩阵与拾取、启动生命周期和构建检查通过。

数据与图片保存在交付目录 `evidence-0.2.4/`。测试使用隔离配置和合成曲库，没有修改日常音乐数据。大量独立大图、不同 GPU 和长期运行不在本轮测量范围内。
