# 0.2.12：玻璃着色、抗锯齿和内存

后续更正：0.2.13 对照下载的 0.2.9 发现默认 1× / 自动分级造成画质损失，并修复本版单通道 AO 适配绕过原有柔化混合的问题。本页末尾的画面一致性结果只比较同一实现内部的预处理 / 存储开关，未覆盖旧包完整画面，不能视为与下载原版等画质的证明。默认策略和最终对照以 PERFORMANCE_0.2.13.md 为准。

延续 0.2.11 的代理模型、纹理预处理与阴影/AO 缓存。这一轮保持默认 60 FPS、100% 渲染比例、256px 音乐架封面与 1024px 近看封面，直接减少实际绘制和存储成本。

- 玻璃场景先用廉价深度着色器找出最前表面，再运行物理材质，跳过被层叠音乐盒挡住的昂贵片元。折射所需的独立不透明背景仍完整绘制，不改变玻璃透光、光带、封面或动效。
- 封面图集从固定 624 张容量改为起步 192 张，按实际使用扩容；未引用的旧封面先复用，刷新资料库后释放扩大的分配。原有稳定槽位与拾取编号保持一致，扩容通过受预算限制的上传队列重建；重建期间尚未上传的封面暂时隐藏。
- AO 与模糊只保存单通道 R16F，保持原有 16 位精度；移除这两个全屏缓冲不使用的深度附件。1080p 合计减少约 39.6 MiB GPU 附件，4K 约 158.2 MiB。关闭 AO 时释放其全尺寸目标。
- 新增轻量 FXAA，位于色调映射之后，实际处理最终输出边缘。新默认“原始”和“性能”预设使用 FXAA；旧设置中的关闭/SMAA 选择保留。SMAA 关闭时释放其大尺寸目标。画质选择同步至 360° 查看器。
- 主画面和查看器关闭无效/重复的画布 MSAA：离屏后处理的几何锯齿应由正确的最终抗锯齿路径处理，而不是仅平滑屏幕上的全屏三角形。

## 验证

`npm test`、`check-quality.mjs`、`check-music-cover.mjs`、`check-gpu-cost.mjs` 和 `check-render-memory-aa.mjs` 覆盖设置兼容、内存扩容/复用/释放、GPU 上传方向、深度预处理画面一致性、AO 存储格式一致性与抗锯齿边缘误差。

1920×1080、1000 专辑测试中，当前工作集 136 张封面的图集由 156 MiB 降至 48 MiB（CPU 画布和 GPU 纹理各减少 108 MiB）；实际同时需要超过 192 张封面时按需增大，最坏容量仍有原来的上限。连续动效的初测主场景 GPU 时间约由 1.78 ms 降至 1.12 ms。任务管理器占用受窗口尺寸、GPU 时钟和其他工作负载影响，不能由这一数值直接换算。

FXAA 的独立斜线覆盖测试对比 8×8 子像素参考，边缘平均误差从 16.27/255 降到 6.28/255，平坦区域无变化。扩容前/后的旧、新封面均通过 GPU 像素读回验证，连续替换 1000 张隐藏封面不再触发额外扩容。

原生窗口的前后对测与最终结果保存在本地 `.cache/gpu-cost/`，不包含真实曲库或个人设置。

## 原生窗口对测

同机 Electron 原生窗口、1920×1080、1000 张合成专辑、12 个流派，昼夜连续切换专辑各 6.5 秒。读取各自隔离测试实例 GPU 进程的 Windows 3D 引擎/进程显存计数器（每段 6 个样本）；用户正在运行的主实例没有重启或改动。

| 指标 | 0.2.11 | 0.2.12 |
| --- | --- | --- |
| 日间 3D 中位数，取整 | 14% | 12% |
| 夜间 3D 中位数，取整 | 15% | 12% |
| 日间专用显存中位数 | 983 MiB | 817 MiB |
| 夜间专用显存中位数 | 989 MiB | 845 MiB |
| 实际提交帧率 | 约 57–58 FPS | 约 57–58 FPS |
| 上限 / 渲染比例 / 密度上限 | 60 / 100% / 1× | 60 / 100% / 1× |
| 抗锯齿 | 原始（关闭后处理 AA） | 轻量 FXAA |

该原生场景的 612 个槽位几乎全是不同专辑，因此两版图集都扩至最大 156 MiB；上述显存下降不依赖“小曲库”的图集节省。进程私有内存统计合计同时减少约 145 MiB，但它包含 Chromium、驱动和宿主资源，不能当作插件 JavaScript 堆大小。

未在隔离测试中复现用户报告的 25% 场景，不能把本次结果描述成“25% 降到 12%”。以上是短时导航样本，不是长期稳定占用保证。帧率使用实际场景提交统计；约 132 Hz 的页面 RAF 回调频率不作为渲染 FPS。

最终画面对比中，日/夜、抽出近看、真实阵列均无差异；总览仅 10 个颜色通道相差 1/255，最大差异 1/255。AO 单通道与原 RGBA 存储的最终画面完全一致。构建、19 项测试、32 项展示/导航检查、封面扩容及 GPU 读回、三档抗锯齿切换均通过。
