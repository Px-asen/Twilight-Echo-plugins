# 0.2.8 歌词页实施记录

## 确定接口
- 单一 ArchiveScene / MusicPresentation：album 与 lyrics 内容共享抽出、切换、返回流程。
- 实际播放曲目驱动；原入口以稳定专辑 ID、详情页签、滚动和总览快照恢复。
- 宿主 bridge v2：player.lyrics / lyrics 事件 / player.seek；不修改宿主与私人曲库。
- 播放时钟不乘界面动画速度；歌词内容只在曲目或内容变化时解析。
- DOM 窗口最多 48 行，布局测量只在内容、字体、宽度与窗口成员变化后进行。

## 来源
src/lyrics/vendor 的八个纯模块复用 Twilight Echo，本地源码快照基于

## 验证

2026-10-18，使用 MessageChannel bridge v2 隔离宿主夹具、12 张合成专辑和真实 WebGL 场景完成验证；未读取私人曲库或修改日常宿主配置。

### 阅读与播放

- LRC 整句、增强 LRC／YRC／TTML 逐字、独立及内嵌译文、多行换行、空白间奏、纯文本、无歌词、失败重试通过。逐字中间值实测为 25% 和 50%。
- 同一份歌词在临时失败后重试，复用成功解析的缓存并恢复正文；快速响应也先完成原内容退场，再替换入场。TTML 相对结束时间和嵌套／直接背景词层有单元回归。
- 点击定时行、拖动进度、上一首／播放暂停／下一首、暂停、缓冲与 2× 倍速通过；将界面动画速度改为 3× 后，歌词时间和词填色保持不变。
- 手动滚动不触发音乐架导航，停止操作 5 秒后恢复跟随；当前句位置实测位于歌词阅读区 38%。
- 同专辑切歌不重新抽出，跨专辑沿用展示流程；同专辑详情切入歌词，也等待新镜头构图就绪后再显示文字。快速连续切歌与旧请求迟到通过。
- 播放区和工作台共用入口。进场中关闭、退场中重开、Esc、返回浏览专辑／详情页签／滚动位置／总览、曲库刷新、原专辑移除通过。关闭不暂停播放。
- 空曲库中的外部播放可使用只供展示的封面与元数据，不向曲库追加专辑。外部封面加载失败回主题默认图的 GPU 封面测试通过。

### 画面与性能

人工检查晨雾／月影的 1440×960 横屏及 390×844 竖屏实际截图。竖屏 CD 中心为 (195, 173)，阅读区从约 y=304 开始、宽 346px，无横向溢出；保留 CD 拖动和默认封面抽出显现、回位恢复行为。

同一台机器的 Edge headless、1440×960、原画质，使用现有主帧统计各取 240 帧：

| 场景 | 主帧 CPU 提交 p95 | 帧间隔 p95 | 最大帧间隔 | 超过 50ms |
| --- | ---: | ---: | ---: | ---: |
| 当前专辑详情页 | 1.3ms | 5.6ms | 5.7ms | 0 |
| 千行歌词页，停在第 501 行 | 1.6ms | 5.6ms | 5.7ms | 0 |

歌词阅读器自身 CPU p95 约 0.1ms。这些数值是本机浏览器的 CPU 提交时间和帧间隔，GPU 执行耗时未单独测量。

两页有效画质参数完全相同：像素比 1、透射 1、各向异性 16、AO 32 采样且全分辨率、阴影 2048、景深 100；抗锯齿沿用原画质配置的 off，未为歌词页下调设置。

- 1000 行歌词仅挂载 19 行 DOM，上限 48。行高只在内容、宽度、字体或窗口成员变化后测量；连续稳定 2 秒，测量计数保持 1494，不逐帧读取布局。
- 正常逐字播放使用时间游标和正在演唱的词集合，只更新跨时间点的词与填色中的词；挂载和 seek 时校准可见词。
- 稳定歌词帧内封面纹理 version 保持 9，图集上传调用保持 9；图形库存保持 8 个 geometry、21 个 texture、29 个 program。歌词不触发封面刷新。
- 全页只有一个 canvas。模拟进入后台后停止主循环，恢复时用宿主进度校准；关闭后不继续解析歌词。pagehide 释放唯一 renderer，canvas 与歌词渲染行均归零。
