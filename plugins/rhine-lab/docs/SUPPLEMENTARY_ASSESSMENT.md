## 保留与适配

- boot-tracks.ts、boot-logo-tracks.ts、boot-orbit-tracks.ts 原样保留（仅换行规范不同）。
- boot-motion.ts 保留原版所有几何、25 fps 切点与约 21.92 秒时长；只更换被逐字显示的文本。
- boot.ts 保留标志描边、圆环、卫星、背景、闪切、欢迎页及白场退出。移除补充项目主题系统依赖，使用原版默认浅色；新文字使用音乐项目已带的 MiSans，不依赖未随 Git 提供的授权字体。
- 开场 CSS 独立作用域，保留原始规则及响应式中央画布。仅按 Twilight Echo 文字长度调整字号、字距和文字框宽度。
- 标志下的 Twilight Echo 文字按 310 单位图形中心对齐；整句先排版，再逐字显示，避免替换文字后偏左或逐字出现时横向漂移。欢迎页标志文字同步修正。
- 加载与动画并行；动画和资源均完成后进入主项目音乐架。原音乐版 2D 前言不再重复出现，5.2 秒三维入场保持原有逻辑。
- 原版进入按钮对应提前结束开场；若资源未就绪则等待，失败显示详情及重新加载。设置中的“重播开场”也使用这段动画。
- 不使用 animate 技能重设计跳过、减少动态或动画曲线；既有音乐界面的显式减少动态偏好继续生效。
