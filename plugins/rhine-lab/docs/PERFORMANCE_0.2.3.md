# 莱茵生命 · 0.2.3 性能优化

保留原始画质与动画设置，优化连续移动中的重复渲染、纹理传输和输入计算。此版继续兼容之前交付的 Twilight Echo 预览宿主，安装 `.tep` 升级即可。

## 改动

- 同一张封面的实例复用已驻留的图块，循环换位和返回时优先调整 UV；使用原纹理网格的空余格缓存，不扩大图集。
- 同行脏图块合并上传，仍限制每帧最多 2 MiB。分散上传也共用一批状态设置。
- 在本场景独占的 WebGL 上下文中跟踪 unpack 状态写入；加载时读取一次初始状态，移动中不再同步查询 GPU。支持多个图集共用上下文，释放最后一个使用者时恢复原方法。Three r183 之外或无法取得目标纹理时回退公共 API。
- CD 壳各部件和封面共享同一实例矩阵缓冲，取消每帧六份相同数据的重复写入和传输。
- SSAO 与景深同分辨率时共用本帧深度，省去一遍完整场景的深度绘制。AO 关闭或低于全分辨率时保留原景深路径；处理 125%／150% 渲染比例的整数像素尺寸。
- 高频鼠标移动合并为每帧一次悬停拾取；视差和拖拽仍立即更新，点击仍即时拾取。

## 默认画质移动对比

同机打包 EXE，隔离配置，默认图形后端，3 张合成专辑；每 650ms 换位、定期反向，每段约 6.5 秒。两版均开启相同 CPU profiler，因此数据含采样开销。P95／P99 表示帧间隔分位数，越低越顺畅，不代表最大卡顿时间。

实际 WebGL：`ANGLE (NVIDIA, NVIDIA GeForce RTX 5070 Laptop GPU (0x00002D18) Direct3D11 vs_5_0 ps_5_0, D3D11)`，原生测试的 devicePixelRatio 为 1.5；窗口尺寸不是降低画质后的内部渲染分辨率。

| 1366×768 | 月影 | 74.0 → 173.2 | 27.7 → 5.7 ms |

## 画质与正确性

- 画质预设、分辨率比例、封面尺寸、2048 阴影、32 样本 AO、景深参数、全分辨率玻璃折射和各向异性参数保持原值。20 个画质、材质、光照、相机、运动及开场源文件与 0.2.2 逐字节一致。
- 在 1366×768、1920×1080、900×1200 的晨雾、月影、黄昏及近景、详情、总览中，冻结场景比较原深度路径与共享深度，共 27 组。最大平均 RGB 通道差为 0.720/255；最大有 1.507% 的像素在某通道上相差超过 8。不是逐像素相同，差异主要在景深边缘，已人工检查对照图。
- 原景深绘制计入约 223 万三角形，重用深度后约 161 万；几何体和可见 CD 数量未减少。保留原 Bokeh 采样核及焦距、光圈和模糊上限。
- 实际 GPU 读回验证连续、分散、跨行图块与独立整图上传完全一致，包括透明区域。缓存回收、异步图片、UV 归属、2 MiB 预算、非默认 unpack 状态恢复及公共 API 回退通过；热身后的图块上传同步状态查询数为 0。
- 512 次同帧指针事件只触发一次悬停拾取，目标与原拾取一致；离开画布取消待处理事件，退出释放上下文。
- TypeScript／Vite 构建、4 项单元测试、光照与入场、交互、实际列矩阵／射线拾取和场景检查通过。最终打包 EXE 安装、完整开场、播放、工作台、三个独立窗口及权限隔离通过。

## 安装及文件

在兼容预览宿主的“设置 → 插件”安装 `com.twilightecho.experience.rhine-lab-0.2.3.tep`。已有宿主无需重新下载。源码为 `RhineLab-0.2.3-source.zip`，包含 content、参考代码和美术源文件。`performance-comparison/index.html` 可切换尺寸／主题／视图并拖动对照，证据在 `evidence-0.2.3/`。

测试均使用独立配置及合成数据，未修改日常应用配置，也未提交或发布到远端。
