- 保留原版 CD 盒、晨雾／月影、音乐架入场、光照、相机、三维阵列、总览、详情、标题动效和资料交换。源码及资源对照见 docs/UPSTREAM_AUDIT.json。

- 托盘、桌面歌词、迷你播放器使用莱茵皮肤及原有窗口生命周期；保留各自受限的 preload API。
- 按本次要求将 RhineLabUI 原版开场接入加载，文案为 Twilight Echo；保留其几何轨迹与 25 fps 时间轴。加载就绪后接主项目原有 5.2 秒三维音乐架入场，不再播放旧 2D 音乐前言。详见 docs/SUPPLEMENTARY_ASSESSMENT.md。

## 0.2.8 音频档案歌词页

- album / lyrics 共用原有展示状态机、相机和 WebGL 场景；横屏左侧 CD 约 42%，竖屏 CD 上置，当前行锚定歌词阅读区 38%。保留抽出封面显现和 CD 拖动。
- 播放区与工作台共用入口；歌名仍定位歌曲。提供上一首、播放暂停、下一首、进度拖动、定时行 seek、译文开关、5 秒恢复跟随和返回原位置。
- 复用带 Apache-2.0 来源与许可的宿主歌词解析模块；支持 LRC、增强 LRC、YRC、TTML、翻译和纯文本。请求按曲目 ID 与序号隔离；空歌词／失败分别呈现并可重试。
- 实际播放驱动 CD 与歌词，同专辑不重新抽出，外部歌曲使用只供展示的记录，曲库无临时插入。返回按稳定专辑 ID 恢复；原专辑移除时回音乐架。
- 按宿主进度、实际倍速校准独立播放时钟；歌词不受界面动画速度影响。仅在内容变化时解析，最多 48 行 DOM，逐帧只处理可见行及正在填色的词；宽度／内容／字体变化后测量行高。页面关闭／后台停止歌词动画。
- 详细实测与画质、资源数据见 docs/LYRICS-0.2.8.md。本版不改宿主、桌面歌词窗口、歌词搜索及编辑器。

## 0.2.7 默认封面与抽出动效

- 默认封面按主题统一：晨雾使用日光沙丘，月影使用月夜海面。设置自动保存，关闭后恢复专辑原图。
- 完整抽出专辑时渐显真实封面，放回时渐隐；背景专辑架及搜索缩略图保持统一默认封面。缺少或无法加载原图时使用既有文字封面。
- 抽出和回位以 GPU 双纹理混合实现，动画逐帧只更新 uniform；原图按需解码、复用 1024px 纹理并沿用现有队列与缓存。快速切回未归位专辑时接续当前封面状态。
- 浏览器 WebGL 像素检查覆盖混合中间帧、独立回位副本、反向与快速重选、迟到图片、画质切换及资源释放；完整界面检查覆盖抽出／回位、双主题、偏好重载和恢复原图。

## 验证范围与后续工作

这是可试用的本地预览交付。未完成所有原始规划中的高级编辑器重制：完整主题图像／图层编辑器、全部 DSP／原生插件工作流及高级设备控制仍需进一步实现或验证。

测试均使用隔离配置及合成数据，未向日常用户配置安装插件。需要本次包含新增服务能力的 bridge v2 宿主；仅版本号相同的旧二进制不保证兼容。
